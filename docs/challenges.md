# Partner-Challenges und Kriterien

Quelle: die Challenge-Briefs von aiagentsberlin.xyz/agentic-hackathon. Abgabe für alle: 19:45 CET.

## idealo — Build Something We Didn't Expect (Agentic Commerce)

Preis: Wunschgutscheine im Wert von 300 € für "Most Creative Use of the idealo MCP".

| Kriterium | Frage |
|---|---|
| Creativity | Nutzt das Projekt den idealo-MCP auf unerwartete Weise? |
| Meaningfulness | Welches echte Problem löst es, und für wen? |
| Use of the data | Wie treiben Produkt-, Preis-, Verfügbarkeits-, Händler- oder Kategoriesignale das Ergebnis? |
| Execution | Macht der Prototyp die Idee greifbar? |

Der MCP liefert: Produktkatalog, Kategorie-Beziehungen, aktuelle und historische Preise,
Verfügbarkeit, Händler, Angebote.

## Nebius — Evidence to Action (beide Tracks)

Preis: Token-Factory-Guthaben im Wert von 500 US$.

| Kriterium | Punkte |
|---|---|
| Token Factory use | 35 |
| Usefulness | 30 |
| Handling uncertainty | 25 |
| Clarity | 10 |

Pflicht:
1. Modell-Calls des Agenten laufen über die Token Factory. Die Entscheidung kommt aus einem Live-Call.
2. Ein einfacher Fall.
3. Ein Fall mit fehlenden oder widersprüchlichen Daten.
4. Die Calls zeigen: Log, Trace oder Usage-View.

Abgabe: Demo oder lauffähiger Prototyp, den die Jury öffnen kann, plus kurze Notiz (Modellnamen, wo
der Call entscheidet).

## Norma by Quality Clouds — Ship agent code your team can defend (beide Tracks)

Preis: 6 Monate Norma Pro plus 150 €.

| Kriterium | Punkte |
|---|---|
| Policy und Konsistenz | 30 |
| Bewusst akzeptiertes Finding (mit Begründung) | 30 |
| Gefunden und behoben | 20 |
| Production-Ready Score | 20 |

Pflicht:
1. Jeder Autor (Mensch oder Agent) läuft unter denselben Norma-Checks (MCP: https://api.qualityclouds.ai/mcp).
2. Mindestens 2 PRs von verschiedenen Autoren, vom Norma-GitHub-App geprüft.
3. Mindestens ein Finding behoben.
4. Eine Norma-Policy im Workspace angelegt.

Extrapunkte und Tiebreak: Norma im Agent-Loop (der Agent prüft vor dem Commit).
Anmeldung: norma.qualityclouds.com?ref=agentic-berlin, Workspace nach dem Team benennen.
