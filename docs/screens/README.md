# Screens (as of 28 November 2026)

Every current screen of Wishfit in the iOS app (simulator), the web app and the PWA (emulated standalone), for work on the user journey and the design.

- `index.html`: gallery, native | web | PWA side by side (open locally in a browser)
- `screens.md`: per screen purpose, entry, next steps, states, texts and observations
- `journey.md`: user journey as a Mermaid flowchart
- Images: WebP, scaled to half size. The full-size PNGs and a PDF are on the build machine.

Gaps (see screens.md): some native screens are missing; there is no recommendation with prices yet, because the idealo access was down at the time of capture; admin screens use mocked data.
